# Zed, unofficial study

## Direction

Reference: the captured zed.dev home (2026-09-21, 1440x900, 8,206px). Mood: a technical drawing on warm paper, serif titles and mono body. Signature: the editor is live - the buffer types a keyboard-navigation fix line by line, with the current line tinted and a blue caret.

## System

- Type: Lora italic 500 for the hero and serif section titles; IBM Plex Mono body; Inter for UI labels.
- Palette: paper `#f6f5f1`, ink `#1c1d22`, grey `#5a5c63`, hairline `#dcdad3`, blue `#084ccf`, highlight `#d4e1fb`, graph paper `#d9e3f7`.
- Motion density: blur hero, typed buffer, caret (paused offscreen), card reveals.

## Techniques

- Horizontal rules ending in rotated-square markers, framed by vertical page hairlines.
- Keyboard shortcut chips inside buttons.

## Layout Floor

Sticky blurred header; the editor keeps only the code pane below 960px; trio, voices, and feature grids stack.

## Comparison With The Original

Reviewed side by side at 1440x900 against 7 capture frames (`.tmp/compare/zed.jpg`).

- Matches: warm paper ground with vertical page hairlines, a sticky header with a blue Download button carrying a shortcut chip, a thin news line, a centered italic blue serif headline with blue and outlined buttons, a three-point strip divided by hairlines, an editor window (file list, agent thread, code buffer), serif section titles with right-aligned bordered actions, a testimonial grid with one highlighted blue card, dark feature shots in a hairline grid, an extension card grid that fades toward the bottom, a letter card on blue graph paper.
- Deliberate differences: the buffer types an agent's edit live; companies, quotes, and extension names are invented; the letter is signed by the study, not a company.
- Remaining gaps: study 3,940px vs 8,206px; the original's "built with care" LSP section and blog row are omitted.
