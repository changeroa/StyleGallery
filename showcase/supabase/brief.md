# Supabase, unofficial study

## Direction

Reference: the captured supabase.com home (2026-09-21, 1440x900, 7,747px). Mood: quiet engineering paper with one mint accent. Signature: the database card is alive - new rows land in its table while you watch, and the client tabs swap code and result together.

## System

- Type: Inter 500 at -0.04em for display; JetBrains Mono for tables and code.
- Palette: ground `#fcfcfc`, ink `#171717`, grey `#5f5f5f`, hairline `#e6e6e6`, mint `#3ecf8e` (text `#1f7a53`); story gradients pink-red-orange, navy, teal, black.
- Motion density: split hero, row inserts, realtime blips (paused offscreen), reveals.

## Techniques

- Two-tone headings (one line ink, one grey) and two-tone card copy (bold lead, grey rest).
- Hairline bento with 6-column spans.

## Layout Floor

Sticky blurred header; bento goes to two columns below 900px; code and result stack below 760px; stories go 4, 2, 1 columns.

## Comparison With The Original

Reviewed side by side at 1440x900 against 7 capture frames (`.tmp/compare/supabase.jpg`).

- Matches: off-white page with a thin sticky header and a mint CTA; a two-line hero whose second line is mint; hairline product cards (database, auth, functions, realtime, vectors) with small tables and two-tone copy; a two-tone section head over pill tabs and a code panel; a two-tone head over tall gradient story cards (pink-red-orange first, then navy, teal, black); a closing CTA and link footer.
- Deliberate differences: the hero is centered rather than split left/right; new rows land in the database table live; the tabs swap code and result; customers and stories are fictional; the elephant mark and community tweet wall are not used.
- Remaining gaps: study 2,767px vs 7,747px; the original's template gallery and community wall are omitted.
