Questions people ask

what is a software factory?

In this study: a file that says which agents work on which repos, with which models, and how their work is checked.

do i have to use your models?

No. The study assumes any model can be plugged in per stage.

where does our data live?

Wherever you choose; the study assumes your cloud or a hosted option.

can we start small?

Yes. One repo, one agent, one check is a factory too.
