04 / AGENT NATIVE

사람이 읽고,
에이전트가 조회합니다.

Markdown 원본은 그대로 유지하면서 CLI와 MCP가 동일한 지식을 결정적 JSON으로 제공합니다. 검색, 조회, 근거 확인은 가능하지만 저장소를 임의로 변경하지는 않습니다.

  • DISCOVER 사용 가능한 인터페이스 탐색
  • RESOLVE StableRef 기반 레코드 조회
  • CONTEXT 토큰 예산 안에서 컨텍스트 구성

05 / PRINCIPLES

복사하기 쉬운 코드보다,
틀리기 어려운 경계.

  • 01

    Semantic first

    레이아웃 클래스보다 문서 구조와 읽기 순서를 먼저 결정합니다.

  • 02

    One spatial problem

    각 패턴은 하나의 주요 공간 문제에 집중합니다.

  • 03

    Explicit ownership

    스크롤, 제약, 근거와 변경 책임을 숨기지 않습니다.

  • 04

    Portable by default

    프레임워크보다 평범하고 견고한 HTML과 CSS를 우선합니다.
